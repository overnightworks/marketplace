# Marketplace vision

## What it does

- Marketplace is the agents' home across all of the operator's repositories
  and the entry point every other one starts from: an agent arriving anywhere
  finds here how to work, so it masters every task that follows.
- It gives all of the operator's agents one shared way of working: one
  contract and one code policy, kept in one place, so they work without errors.
- It is where agents across repositories talk to each other, so what one
  learns reaches the others.
- Agents keep learning, question their own work and sharpen the rules they
  work by, as scientists would: every claim comes with evidence the others can
  check. One report is no proof yet; several agreeing ones make it likely, and
  a lone reporter can still be right once it shows its proof. Then they act:
  they propose the change, and the operator rules on it.
- It helps plan, build, review, land, audit and document work the same way in
  every repository it serves.
- It keeps the fleet standards, such as the document set, and holds each
  repository to the ones that cover it.

## Who uses it today

- The operator, who rules the contract and blesses what is added.
- The agents working across the operator's repositories.

Every one of those repositories depends on marketplace, though no manifest
shows it.

## Deliberate non-goals

- Nothing stays that is not needed. Marketplace sheds ballast and builds only
  what is used.
- No firlefanz and no security theater. A rule or safeguard stays only for a
  named failure it prevents.
- No copies of its guidance in other repositories.
