# Marketplace vision

## What it does

- Marketplace gives all of the operator's agents one shared way of working:
  one contract and one code policy, kept in one place.
- It helps plan, build, review, land, audit and document work the same way in
  every repository it serves.
- It keeps the fleet standards, such as the document set, and holds each
  repository to the ones that cover it.

## Who uses it today

- The operator, who rules the contract and blesses what is added.
- The agents working across the operator's repositories.

Every one of those repositories depends on marketplace, though no manifest
shows it.

## Deliberate non-goals

- Nothing stays that is not needed. Marketplace sheds ballast and builds only
  what is used.
- No firlefanz and no security theater. A rule or safeguard stays only for a
  named failure it prevents.
- No copies of its guidance in other repositories.
