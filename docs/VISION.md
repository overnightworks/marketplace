# Marketplace vision

## What it does

- Marketplace is the agents' home across all of the operator's repositories,
  and the entry point every other repository starts from. An agent that
  arrives anywhere finds here how to work, so that no follow-up task begins
  from nothing.
- It gives all agents one shared way of working, one contract and one code
  policy kept in one place, so they work without errors and master each task
  that follows.
- It is the place where agents across repositories talk to each other, so
  what one learns reaches the others.
- Agents keep learning from their own runs and question their own work. They
  propose and sharpen the rules they work by; the operator rules on each
  change.
- Agents back each rule change with evidence they can show and share: one
  report is a hint, several agreeing reports are a signal, and a lone
  reporter can be right, if it proves its case before anyone acts on it.
- It plans, builds, reviews, lands, audits and documents work the same way in
  every repository it serves.
- It keeps the fleet standards, such as the document set, and holds each
  repository to the ones that cover it.
- It fits the fleet's work to the operator's usage allowance and brings him
  only what needs him.

## Who uses it today

- The operator, who rules the contract and blesses what is added.
- The agents working across the operator's repositories.

Every one of those repositories depends on marketplace, though no manifest
shows it.

## Deliberate non-goals

- Nothing stays that is not needed. Marketplace sheds ballast and builds only
  what is used.
- No firlefanz and no security theater. A rule or safeguard stays only for a
  named failure it prevents.
- No copies of its guidance in other repositories.
